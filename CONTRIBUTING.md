# Contributing

This repository is a focused research prototype. Contributions should keep the retrieval and agent behavior understandable, reproducible, and safe to evaluate.

## Before opening a change

- Explain the problem and the smallest useful change.
- Do not commit API keys, tunnel URLs, uploaded documents, model weights, or personal data.
- Update the relevant README or architecture note when behavior or setup changes.
- Run `flutter analyze` from `frontend/flutter_app` when changing the Flutter client.
- Include a short evaluation note for changes to retrieval, prompting, chunking, or model behavior.

## Pull requests

Keep pull requests focused. Include what changed, how it was tested, and any known limitation or behavior trade-off.
